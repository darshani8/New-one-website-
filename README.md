# The Enchanted Tome — A Cinematic, Interactive 3D Storybook

A self-contained, movie-intro-style 3D storybook that runs in the browser.
Open `index.html` and a leather-bound tome fades in out of warm darkness:
the camera dollies in, the cover lifts open, a page turns, and a glowing
gold title writes itself onto the page — then control is handed to you for
a free, damped orbit.

This is the first working version of the roadmap *"From Realistic Book to
Movie-Intro Magic."* It is built on **Three.js** (which React Three Fiber
wraps verbatim, so this scene migrates to R3F with zero visual change).

## Run it

It's a single file with **no build step**. Either:

```bash
# just open it
open index.html            # macOS  (xdg-open on Linux)

# …or serve it (recommended; avoids any module/CORS quirks)
python3 -m http.server 8000
# then visit http://localhost:8000
```

> An internet connection is required: Three.js (`0.160.0`) and GSAP
> (`3.13.0`) load from a CDN via an ES-module import map. All textures and
> lighting are generated **procedurally**, so no asset files are needed.

## Controls

| Action            | Input                          |
| ----------------- | ------------------------------ |
| Orbit             | drag (left mouse / touch)      |
| Zoom              | scroll / pinch                 |
| Turn the page     | **Turn the Page** button       |
| Replay the intro  | **Replay Intro** button        |

The orbit is clamped so you can't go under the table or zoom through the book.

## What's in the scene (and where the realism comes from)

Realism is **~80% lighting + post-processing**, not geometry. The pipeline:

- **ACES Filmic tone mapping** + IBL from a procedural `RoomEnvironment`
  (PMREM) — the single biggest realism lever. Gives soft ambient light and
  the reflections that make leather and gilt read as real.
- **`MeshPhysicalMaterial` leather** with a full procedural PBR map set
  (albedo + normal + roughness, generated by value-noise FBM) and a light
  `clearcoat` for the waxed/oiled sheen.
- **Modelled silhouette, normal-mapped texture**: the raised spine bands and
  cover thickness are real geometry (they catch light on a 360° orbit); the
  grain is a normal map.
- **Post-processing chain** (`EffectComposer`): RenderPass → selective
  **UnrealBloom** (only emissive > 1 glows: the title, sparkles, the shaft)
  → a custom **grade pass** (chromatic aberration + vignette + film grain) →
  **OutputPass** (ACES + sRGB).
- **Atmosphere**: warm `FogExp2`, a procedural additive **god-ray shaft**,
  and ~480 GPU **dust sparkles** (custom `Points` shader, additive, drifting
  + twinkling).
- **Skinned-mesh page-turn rig**: each page is a subdivided plane driven by a
  20-bone chain, bent procedurally each frame and eased with damping — the
  production-proven page-turn technique.
- **Three-point lighting**: warm directional key (the only shadow caster,
  PCF-soft) + cool rim for separation + a soft `RectAreaLight` "window."
- **GSAP timeline** choreographs the intro beats, then hands off to damped
  `OrbitControls`.

## Tuning

Most knobs live in the `CFG` object at the top of the `<script type="module">`
in `index.html` — book dimensions, page count, turn/open angles, bloom
strength/threshold, and exposure.

## Upgrading toward photoreal

Everything below preserves the exact rendering path, just raises fidelity:

1. **Drop in real assets.** Replace `makeLeatherMaterial()` with CC0 PBR maps
   (albedo/normal/roughness/AO/height) from **Poly Haven** or **ambientCG**
   (downscaled to 1–2K, ideally KTX2/Basis), and swap the procedural
   `RoomEnvironment` for a real `.hdr` via `RGBELoader`.
2. **Model the book in Blender**, export Draco-compressed glTF, and load it
   with `GLTFLoader` + `DRACOLoader` instead of the box primitives.
3. **Add Depth of Field** (pmndrs `postprocessing` `DepthOfFieldEffect`)
   focused on the book for true bokeh, and an optional LUT color grade.
4. **Migrate to React Three Fiber** + `drei` + `@react-three/postprocessing`
   when the scene grows — `<Environment>`, `<Sparkles>`, `<AccumulativeShadows>`,
   `<CameraControls>`, and declarative `<EffectComposer>` replace this
   hand-wired plumbing with no loss of fidelity.
